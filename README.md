# stefanos-papadakis.gr

Η νέα έκδοση του προσωπικού επαγγελματικού site του Στέφανου Παπαδάκη, Senior Insurance Agent @ NN Hellas και Financial Planner.

Είναι στατικό site χωρίς build, με HTML, CSS και λίγη JavaScript, και φιλοξενείται στο **GitHub Pages**.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `index.html` | Η ελληνική σελίδα του site |
| `en/index.html` | Η αγγλική σελίδα του site, στο `stefanos-papadakis.gr/en/` |
| `assets/img/` | Φωτογραφίες, λογότυπα και εικονίδια |
| `CNAME` | Λέει στο GitHub ότι το domain είναι το `www.stefanos-papadakis.gr` |
| `404.html` | Σελίδα για λάθος διευθύνσεις. Μετά από 6 δευτερόλεπτα στέλνει τον επισκέπτη στην αρχική |
| `robots.txt`, `sitemap.xml` | Βοηθούν τη Google να βρει και να καταχωρίσει το site |
| `favicon.ico` | Το εικονίδιο στην καρτέλα του browser |
| `.nojekyll` | Λέει στο GitHub να σερβίρει τα αρχεία όπως είναι, χωρίς επεξεργασία |

## Οδηγίες ανεβάσματος (μία φορά)

### 1. Δημιούργησε το repository
1. Μπες στο https://github.com με τον λογαριασμό σου (π.χ. `stefos79`).
2. Πάτα **New repository**.
3. Όνομα: `stefanos-papadakis.gr` (ή ό,τι θέλεις).
4. Επίλεξε **Public**, γιατί το GitHub Pages στον δωρεάν λογαριασμό θέλει δημόσιο repository.
5. Πάτα **Create repository**.

### 2. Ανέβασε τα αρχεία
1. Στη σελίδα του νέου repository πάτα **uploading an existing file** (ή **Add file → Upload files**).
2. Σύρε **όλα** τα αρχεία και τους φακέλους `assets` και `en` από το zip. Το `index.html` πρέπει να είναι στη ρίζα και όχι μέσα σε υποφάκελο.
   - Το `.nojekyll` είναι κρυφό αρχείο και μπορεί να μη φαίνεται. Αν δεν ανέβει, δεν πειράζει.
3. Πάτα **Commit changes**.

### 3. Ενεργοποίησε το GitHub Pages
1. **Settings → Pages**.
2. **Source:** Deploy from a branch.
3. **Branch:** `main`, φάκελος `/ (root)`, και μετά **Save**.
4. Σε 1–2 λεπτά το site θα είναι διαθέσιμο στο `https://stefos79.github.io/<όνομα-repository>/`.

### 4. Σύνδεσε το domain stefanos-papadakis.gr
Μπες στον πάροχο του domain σου (εκεί που το αγόρασες, π.χ. Papaki, Google Domains/Squarespace, GoDaddy) και άλλαξε τις ρυθμίσεις DNS:

| Τύπος | Όνομα / Host | Τιμή |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `stefos79.github.io` |

- Σβήσε τυχόν παλιές εγγραφές για `@` και `www` που δείχνουν στο Google Sites.
- Στο GitHub, στο **Settings → Pages → Custom domain**, γράψε `www.stefanos-papadakis.gr` και πάτα **Save**. Το αρχείο `CNAME` το έχει ήδη έτοιμο.
- Όταν περάσει ο έλεγχος DNS (από λίγα λεπτά έως 24 ώρες), τσέκαρε το **Enforce HTTPS**.

> **Σημαντικό:** Το site σου σήμερα τρέχει στο Google Sites. Μόλις αλλάξεις το DNS, το domain θα δείχνει στο νέο site. Οι παλιές υποσελίδες (`/about-me`, `/contact`, `/blog`, `/videos`, `/nbs` κ.λπ.) δεν θα υπάρχουν πια και το νέο site δεν τις χρησιμοποιεί και οι επισκέπτες θα βλέπουν τη σελίδα 404, που τους γυρίζει στην αρχική.
> - Στο Google Sites, άλλαξε ή αφαίρεσε το custom domain από τις ρυθμίσεις δημοσίευσης, για να μη συγκρούεται με το GitHub.

### 5. Ενεργοποίησε τη φόρμα ραντεβού
Η φόρμα «Κλείσε δωρεάν συνάντηση» στέλνει τα αιτήματα στο `papadakis.stefanos@gmail.com` μέσω της δωρεάν υπηρεσίας **FormSubmit**.
1. Όταν το site είναι online, συμπλήρωσε και στείλε μία δοκιμαστική φόρμα.
2. Θα σου έρθει email από το FormSubmit. Πάτα **Activate Form**.
3. Από εκεί και πέρα κάθε αίτημα θα έρχεται στο email σου.
4. *(Προαιρετικό, αλλά το συνιστώ)* Το FormSubmit σου δίνει ένα κρυφό αναγνωριστικό, μια σειρά από γράμματα και αριθμούς. Βάλ' το στο `index.html` στη θέση του `papadakis.stefanos@gmail.com`, στη γραμμή `action="https://formsubmit.co/..."`, για να μη φαίνεται το email σου στον κώδικα και να μην το βρίσκουν τα spam bots.

## Ενημερώσεις στο μέλλον
Η σελίδα υπάρχει σε δύο γλώσσες, οπότε αν αλλάξεις κάτι στη μία, κάνε την ίδια αλλαγή και στην άλλη. Το κουμπί **EN / ΕΛ** πάνω δεξιά στο μενού αλλάζει γλώσσα.

Για να αλλάξεις κάτι, άνοιξε το `index.html` (ή το `en/index.html`) στο GitHub, πάτα το μολυβάκι (Edit), κάνε την αλλαγή και πάτα **Commit changes**. Η αλλαγή φαίνεται στο site σε 1–2 λεπτά.
